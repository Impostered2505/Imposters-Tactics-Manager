Imposter's Tactics Manager (ITM) - program for creating and editing football tactics. It supports the creation, addition, import, and export of tactics and players.

Other languages will be added in A.0.2.ITM.

History of versions:

A.0.1.ITM.C - Concept of the future A.0.1.ITM version (new interface, icons, themes, etc.)

A.0.1.ITM - Added ball, improved features, new interface, icons, themes, etc.
